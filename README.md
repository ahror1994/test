# Taptym — маркетплейс канцтоваров (Ош)

Рабочее название: **Taptym** («Нашёл!»). Меняется в одном месте — `packages/shared/src/brand.ts`.

Покупатель видит товары всех подключённых магазинов, сравнивает цены и заказывает из нескольких магазинов в одной корзине. Поставщики получают CRM, а владелец — админ-панель.

## Что внутри

| Папка | Что это | Где работает |
|---|---|---|
| `apps/customer` | Приложение покупателя (Expo / React Native) | Android, iOS (позже), браузер `/` |
| `apps/supplier` | Приложение поставщика «Taptym Бизнес» (Expo) | Android, iOS, браузер `/supplier/` |
| `apps/admin` | Админ-панель (React + Vite) | Браузер `/admin/` |
| `apps/api` | Сервер: API, база SQLite, интеграции, раздача веб-версий | Node.js 22+ |
| `packages/shared` | Общий код: типы, умный поиск, расчёт доставки/комиссии/монет, языки | — |

## Запуск демо

```bash
pnpm install
pnpm demo          # собрать 3 веб-приложения и запустить сервер на :3000
```

Откройте `http://localhost:3000/demo` — там ссылки на все три продукта и демо-доступы:

- Покупатель: `+996700111222`, код `1111`
- Поставщик («Канцлэнд», владелец): `+996555000001`, код `1111` (кассир `+996555100002`, склад `+996555100003`)
- Админ: `admin@taptym.kg` / `admin123` (оператор `operator@taptym.kg` / `operator123`, бухгалтер `accountant@taptym.kg` / `account123`)

Сбросить демо-данные: `pnpm reset-db`, затем перезапустить сервер.

## Интеграции: вставил ключ — заработало

Пока ключи не заданы, всё работает в демо-режиме: QR-оплата открывает демо-страницу банка, SMS-код всегда `1111`, доставка Яндекса считается по формуле, уведомления пишутся в журнал.

Ключи вводятся в **Админке → Интеграции** или через переменные окружения (переменные важнее):

| Интеграция | Переменные |
|---|---|
| MBank (QR-оплата, выплаты) | `MBANK_BASE_URL`, `MBANK_MERCHANT_ID`, `MBANK_API_KEY`, `MBANK_WEBHOOK_SECRET` |
| Бакай Банк | `BAKAI_BASE_URL`, `BAKAI_MERCHANT_ID`, `BAKAI_API_KEY` |
| Яндекс Доставка | `YANDEX_DELIVERY_TOKEN` (`YANDEX_DELIVERY_BASE_URL`) |
| SMS (Nikita.kg и др.) | `SMS_BASE_URL`, `SMS_LOGIN`, `SMS_PASSWORD`, `SMS_SENDER` |
| Telegram | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ADMIN_CHAT_ID` |
| WhatsApp Cloud API | `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID` |
| Push (Expo) | `EXPO_ACCESS_TOKEN` |
| Фискализация | `FISCAL_BASE_URL`, `FISCAL_TOKEN` |

Весь код интеграций лежит в `apps/api/src/integrations.ts`. Telegram, WhatsApp, Expo Push и МойСклад написаны по их публичной документации. У MBank, Бакай Банка, SMS-шлюза и ККМ форматы запросов закрытые: банк или оператор выдаёт их вместе с договором. Когда придут ключи и документация, адаптер нужно сверить и при необходимости поправить — обычно это несколько строк.

Для 1С, МоегоСклада и своих учётных систем есть внешний API поставщика с токеном из кабинета: `GET /api/ext/v1/offers`, `PUT /api/ext/v1/stock` (заголовок `X-Api-Token`).

## Как устроены деньги

- Комиссия, по умолчанию 7%, считается от суммы товаров без доставки и настраивается в админке. В пробный период поставщика (30 дней) комиссия 0.
- У каждого поставщика есть баланс, как у ресторанов в Яндекс Еде: `продажи − комиссия − реклама/услуги − скидки поставщика − наличные, которые он получил сам`.
- Если клиент оплатил онлайн, деньги приходят на счёт площадки и зачисляются на баланс поставщика после доставки.
- Если клиент платит наличными поставщику (его доставка или самовывоз), с баланса поставщика списывается комиссия. Если долг превысил лимит, наличные для его заказов отключаются.
- Если наличные забрал курьер Taptym, они у площадки, и поставщик получает сумму минус комиссия.
- Выплата: поставщик нажимает «Запросить», админ видит готовый расчёт, оператор звонит и подтверждает, затем «Выплатить» (через API MBank или вручную).
- Монеты: 1 монета за каждые 100 сом, 1 монета = 1 сом, ими можно оплатить до 30% заказа. Промокоды создаёт админ, поставщики присылают их на согласование.

## Сборка Android

Мобильные приложения — это Expo-проекты. Для APK нужен адрес сервера, доступный с телефона:

```bash
cd apps/customer            # или apps/supplier
export EXPO_PUBLIC_API_URL=https://ваш-сервер   # адрес, где запущен apps/api
npx eas-cli@latest build -p android --profile preview   # облачная сборка APK (нужен бесплатный аккаунт expo.dev)
# или локально (нужны Android SDK и JDK 17):
npx expo prebuild -p android && cd android && ./gradlew assembleRelease
```

Установка на телефон по USB: `adb install app-release.apk`. iOS собирается из того же кода: `eas build -p ios` (нужен аккаунт Apple Developer).
